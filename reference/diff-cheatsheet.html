Diff & Code-Reading Cheat Sheet

Quick lookup. Print this one out.

Diff symbols

-  line removed
+  line added
   (no symbol) unchanged context line
@@ ... @@   location marker (line numbers, can ignore at first)

The one question to ask of any diff

"What can now happen that couldn't before — or what can no longer happen that could before?"

Reading an unfamiliar function — order of attack

  1. Read the name and the docstring (the quoted text right under def) first
  2. Read top to bottom once, without trying to understand every detail
  3. Find the return value(s) — what does this function hand back?
  4. For each branch (if/elif/else), say in one sentence what triggers it
  5. Only then, worry about the exact syntax of any one line

Common Python control words

  • continue — skip the rest of this loop step, go to the next one
  • break — exit the loop entirely
  • return — exit the function, optionally handing back a value
  • pass — do nothing (a placeholder)

Governance-relevant questions, every time

  • Is this a structural (code) control, or just an instruction (prompt/comment)?
  • Could this run on real personal data? What happens to that data if it does?
  • If this is wrong, who notices — the user, or no one?
